# Scroll Stack

Вставьте Scroll Stack → в слот «Карточки / Repeat» вставьте Scroll Stack Card → внутрь него поместите свой дизайн карточки. Включите Repeat на Scroll Stack Card и свяжите его с существующим результатом fetch. Отдельный повтор — отдельная анимированная карточка. Компонент запросы не меняет.

Для готового повторяющегося компонента можно задать CSS-селектор корней карточек, например `.stackCard`. Селектор выбирает отдельные карточки, а не общую обёртку. При использовании Scroll Stack Card селектор не нужен.

В режиме смены в закреплённой области корню дизайна карточки задайте width и height 100%. Высота больше доступной области обрезается маской. Стили содержимого задаются внутри слота.

Эффекты: stack, deck, fade, flip, zoom, reveal. Настройки: прокрутка на карточку (1 экран по умолчанию), stickyTop (80px под navbar), максимальная ширина (880px), высота карточки (68% доступной области), боковые отступы, скругление, сдвиг, масштаб, глубина, размытие, затемнение, плавность, перспектива, индикатор и счётчик. Событие onIndexChange передаёт индекс с 0.

В редакторе показан список; «Анимация на холсте Studio» включает стек. В интерактивном Preview анимация включается автоматически. На экранах до 767px по умолчанию список; можно включить мобильную анимацию. Системный reduced motion также включает список. Одна карточка не создаёт длинной области прокрутки.

Поддерживается прокрутка окна и ближайшего контейнера overflow-y:auto/scroll, включая документ iframe. Контейнеру нужна заданная высота. Избегайте случайных родителей overflow:hidden, нарушающих CSS sticky. Padding-top:80px корневого элемента страницы TP остаётся; stickyTop отдельно задаёт положение закрепления стека.

Скрытые карточки не получают клики и Tab-фокус. При выключении анимации исходные inline-стили восстанавливаются. Изменение количества элементов Repeat учитывается автоматически. Дополнительные npm-пакеты не нужны.

### Ширина и карточки в Preview

Включите «На всю ширину», чтобы карточки заполняли родительский блок за вычетом боковых отступов. Иначе ширина ограничена настройкой «Максимальная ширина, px» (по умолчанию 880); можно задать 1200, 1440 или больше. Родительский блок также должен быть достаточно широким.

При анимации промежуточные обёртки между рамкой и Scroll Stack Card используют display: contents, чтобы карточки не получали нулевую высоту внутри обёрток слота/Repeat. При переходе к списку исходные стили восстанавливаются. Оформление карточки размещайте внутри Scroll Stack Card, а не на общей обёртке всех карточек.


### Режим «Карточки подряд → стек»

Выберите «Режим прокрутки» → «Карточки подряд → стек». Карточки сохраняют высоту своего содержимого и идут подряд; «Промежуток между карточками, px» задаёт расстояние между ними (по умолчанию 24). Когда карточка доходит до «Отступ под navbar, px» (по умолчанию 80), она закрепляется, а следующая накрывает её. В конце блока стек уходит вместе со страницей. Дополнительные экраны прокрутки не добавляются.

Используйте Scroll Stack Card со слотом и Repeat, как в прежнем режиме. Задайте непрозрачный фон вашему дизайну карточки, чтобы предыдущая карточка не просвечивала. Для карточек желательно выбирать высоту, помещающуюся в экран под navbar; очень высокий контент удобнее показывать обычным списком.

Эффекты deck/fade/flip и другие, высота в процентах экрана, дистанция в экранах, индикатор и счётчик относятся только к режиму «Смена в закреплённой области». В новом режиме эти настройки скрыты. На мобильном устройстве по умолчанию остаётся обычный список; для стека включите мобильный режим «Анимация стека». Настройка reduced motion и отключение стека сохраняют обычный список. На холсте также показан список, а закрепление работает в Preview.


В режиме «Карточки подряд → стек» сохранён эффект Stack: по мере подхода следующей карточки предыдущая плавно уменьшается, смещается назад, размывается и затемняется. Прогресс рассчитывается по высоте карточек и промежутку, без дополнительных экранов. Настраиваются сдвиг, уменьшение за шаг, глубина, размытие, затемнение, скругление и плавность. При прокрутке назад эффект разворачивается.
