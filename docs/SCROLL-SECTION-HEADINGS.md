# Scroll Section Headings

Добавьте компонент из списка Code components в Plasmic. В слоте «Заголовки слева» разместите отдельные заголовки, в «Секции справа» — отдельные контейнеры с пунктами. Первый заголовок соответствует первой секции и т. д. Не оборачивайте весь слот дополнительным общим контейнером. Количество заголовков и секций должно совпадать; секция без парного заголовка остаётся с пустой левой колонкой, лишние заголовки не выводятся.

Вставляется пример из трёх секций. Меняйте текст, типографику, цвет и содержимое самих элементов слотов средствами Plasmic. Настройки компонента управляют шириной колонок, расстояниями, отступом закрепления, линией переключения и длительностью затухания.

По умолчанию заголовки закрепляются в 96 px от верха. Следующий заголовок появляется, когда верх его секции достигает 35% высоты видимой области. Переход длится 0,35 секунды; прокрутка назад работает симметрично. Все заголовки занимают общую область высотой самого высокого заголовка. В конце общего блока закрепление заканчивается.

При ширине окна/iframe до 767 px каждый заголовок выводится над своей секцией. Учитывается системное уменьшение движения. Для закрепления нужен достаточно высокий правый столбец; заголовок должен помещаться в видимую область с учётом верхнего отступа. Не задавайте внешним обёрткам overflow:hidden/auto без необходимости: это меняет область CSS sticky.

ID и target/container-селекторы не нужны. Положение секций и прокрутка читаются из документа самого компонента, включая Preview Plasmic. Изменение размеров содержимого отслеживается автоматически.
